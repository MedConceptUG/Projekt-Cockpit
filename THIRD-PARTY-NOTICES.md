# Komponenten Dritter

Das Projekt-Cockpit verwendet die folgenden Open-Source-Komponenten. Ihre Lizenzen erlauben die
Nutzung in nicht-öffentlicher und kommerzieller Software; bei einer Weitergabe des Programms ist
diese Datei beizulegen.

| Komponente | Verwendung | Lizenz | Quelle |
|---|---|---|---|
| SheetJS Community Edition (`web/xlsx.mini.min.js`) | Excel lesen/schreiben | Apache License 2.0 | https://sheetjs.com · https://git.sheetjs.com/sheetjs/sheetjs |
| pywebview | Programmfenster | BSD 3-Clause | https://github.com/r0x0r/pywebview |
| pythonnet / clr_loader | Anbindung an Windows (.NET) | MIT | https://github.com/pythonnet/pythonnet |
| bottle | interner Webserver von pywebview | MIT | https://bottlepy.org |
| proxy_tools | Hilfsbibliothek von pywebview | BSD | https://pypi.org/project/proxy_tools/ |
| cffi / pycparser | Hilfsbibliotheken | MIT / BSD 3-Clause | https://pypi.org/project/cffi/ |
| PyInstaller (Bootloader) | Verpackung als .exe | GPL 2.0 **mit Bootloader-Ausnahme** – erlaubt die Weitergabe der erzeugten .exe unter eigener Lizenz | https://pyinstaller.org/en/stable/license.html |
| Python | Laufzeit | Python Software Foundation License | https://docs.python.org/3/license.html |
| Microsoft Edge WebView2 | Anzeige der Oberfläche (Teil von Windows) | Microsoft-Lizenz | https://developer.microsoft.com/microsoft-edge/webview2/ |
